Stata 17.5 compatibility check - Trade scripts
Date: 2026-05-27

Summary
- The original Trade_DomExp.do and ImportData\Trade_DomExp_with_import_checks.do start with version 18, so Stata 17.5 will stop before running them.
- The code uses standard Stata commands that are available in Stata 17 once the version statement is changed.
- Monthly export logic was removed from the new yearly-only copies.
- I did not rerun the trade data or regenerate the full previous results.

New Stata 17 yearly-only scripts
- Trade_DomExp_yearly_stata17.do
- Trade_DomExport_Results\Trade_DomExp_yearly_stata17.do
- ImportData\Trade_Import_checks_yearly_stata17.do

Main changes
- Changed version 18 to version 17.0.
- Removed month_num/month creation and dashboard_check_monthly_bc_2025_stata.csv output.
- Separated import checks from the combined export script so the import check script does not stop on the external Trade_Import.csv path.
- Kept yearly 2016-2025 export checks and 2025 vs 2024 YoY checks.

Run order in Stata 17.5, if needed
1. do Trade_DomExp_yearly_stata17.do
2. do ImportData\Trade_Import_checks_yearly_stata17.do
